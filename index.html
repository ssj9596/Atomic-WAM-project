Execution-grounded GRPO

Execution-grounded rewards

With the WAM fixed, EG-GRPO trains the reasoner using rewards for motion appropriateness and execution success.

Propose motions→Execute with WAM→Evaluate rollouts→Update reasoner ↻

Reward definition

rtask · Is this the right next step?1 if the proposed motion is a suitable next step toward the task from the current state; 0 otherwise.

rexec · Did the robot execute it?1 if the rollout successfully completes the specified motion; 0 otherwise.

r = rtask × (0.5 + 0.5 × rexec)

Paper ablation · RoboLab-120, default instructions, three runs: supervised reasoner 36.7% → GRPO without execution reward 34.2% → EG-GRPO 39.2%.

Real-world evaluation

Real-world demonstrations

We train on DROID and deploy on our Franka setup without further fine-tuning.

Our setup uses a RealSense D435 wrist camera instead of DROID’s ZED Mini, with different camera placements and viewpoints.

Our current real-world setup uses synchronous inference. In the videos, pauses are sped up 8× and robot motion is sped up 2×.
